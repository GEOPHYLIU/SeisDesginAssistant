# 模块使用说明索引

本目录按主程序功能树顺序，为 8 个模块各提供一份按模块命名的 `*_使用说明.md`。每份说明覆盖：模块定位、界面结构、输入格式、全部参数、操作流程、结果/输出、校验口径、限制与常见问题；与根目录 `README.md`、内置 `assets/manual.html` 形成“总览—模块—现场操作”三层文档。主程序侧栏每个模块下均有“模块说明”入口，模块页右上角也有“模块说明”按钮。
